# Устройство / Платформа Режим Условие / Задача Время Скорость Итог (Объём / PTS) Дата

📖 Как устроен бенчмарк PiMark

1. Режим Single-Core (Точные знаки π): Использует классическую формулу Джона Мэчина π/4 = 4·arctan(1/5) - arctan(1/239) на базе длинной целочисленной арифметики BigInt.

2. Режим Multi-Core (Все ядра): Создаёт пул параллельных потоков Web Workers и распределяет между ними итерации формулы Бэйли — Боруэйна — Плауффа (BBP) и рядов Нилаканты для 100% нагрузки ядер ЦП.

3. Два критерия тестирования: Вы можете тестировать устройство по фиксированному объёму (замерить, за сколько секунд процессор справится с задачей) или по времени (таймеру) — например, запустить стресс-тест ровно на 60 секунд и узнать точное число вычисленных знаков π или миллиардов итераций.
